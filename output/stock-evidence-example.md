### E4 · 现金流增强与盈利走弱并存

经营质量 / 推断 / 矛盾证据

收入增长、归母利润下降、经营现金流上升同时出现。现金流包含财务公司资金变化，不能直接认定白酒主业经营质量全面改善。

口径：联合核对E1、E2、E3及公司对现金流的解释；非因果证明

来源：S1

下一步：追查现金流附注与销售收现，区分主业和财务子公司贡献。

### E5 · 营业收入口径毛利率下降

### E8 · 历史估值口径试算

估值 / 推断 / 中性证据

以2026-10-15收盘价和2026-06-30股本试算：PE(TTM) 20.16倍，PB 6.53倍。未核验期间股本变化，不是官方当日估值。

口径：TTM归母利润 = 2025FY - 2025H1 + 2026H1；试算市值 = 10月15日收盘价 × 6月30日股本；PE = 试算市值 / TTM归母利润；PB = 试算市值 / 6月30日归母净资产

来源：S1 / S3 / S4

下一步：核验估值日实际总股本、期间分红与回购；补足历史分位和同行估值后再讨论估值判断。

行情特征 / 事实 / 中性证据

口径：价格变化 = 期末收盘价 / 期初收盘价 - 1；最大回撤 = min(收盘价 / 截至当日最高收盘价 - 1)
