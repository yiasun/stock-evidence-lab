# 90–120秒产品演示脚本

0–15秒：展示首页。说明贵州茅台、冻结证据、2026H1观察期；本产品帮助继续研究，不给股票好坏标签。

15–35秒：点击“利润下降，现金流为什么大增？”，检查推荐维度并生成。指出实际运行模式：规则模式或已配置后的LLM导航，不把规则模式说成大模型调用。

35–60秒：查看收入、利润、现金流相反证据，展开E4，说明现金流含财务公司变化。打开原始字段、期次、单位和公告链接。

60–80秒：切换调价问题，展开E6，指出事件晚于半年报期末，后续利润兑现仍未知。

80–100秒：提问当前是否便宜，展示缺少TTM与同日股价时不输出估值。行情沙盒勾选待核验样本，说明区间计算不等于已核实市场结论。

100–120秒：导出JSON记录，展示研究边界与下一步验证任务。

录制前先完成Cloud公网验收；关闭可能含敏感信息的窗口；不要展示Secrets。视频为可选交付，当前仅准备此脚本。
