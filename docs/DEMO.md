## 录制准备

关闭可能含密钥或个人信息的窗口。仅录制产品页面，不展示Secrets、账单或API管理页。确认页面为提交演示版v3、冻结证据提示可见。视频为可选交付；本仓库提供脚本，不声称已录制成片。

免费模型可能拥堵，预留等待。若使用此前成功缓存，应指出缓存标签；若失败，展示明确回退。不要将剪辑、静态截图或规则归纳冒充实时模型输出。

## 0:00-0:25 · 用户与任务

“证据镜面向希望追问证据的个人研究者。我把MVP限定在贵州茅台，让用户从一句问题走到原始披露。这里的财务与行情是冻结快照，不给股票好坏标签。”

展示四张指标卡与观察期。点出收入、归母利润、合并现金流的方向并不一致，后续研究需要区分口径。

## 0:25-1:15 · 问题、AI与证据

点击“利润下降，现金流为什么大增？”，可修改研究维度。侧栏开启“AI证据解读”并生成一次，等待实际结果。

“AI负责关联已有证据与提出待验证问题，财务数字由程序计算。模式标签会明确说明模型结果、缓存还是规则回退。”

展开一条AI引用或E4原始卡，展示财务子公司资金解释、公告链接与页码。“现金流增加不能直接证明白酒主业经营质量全面改善。”

## 1:15-1:55 · 反面证据和未知

切换“调价能改善业绩吗？”。“调价发生在半年报期末之后，当前证据没有期后销量和完整财务数据，不能倒推解释此前业绩，也不能判断影响大小。”

指出E6事件事实与E7未知。若AI段落不符合检查，界面会明确提示隐藏部分内容；校验通过仍需核对原文，不等于已证实因果。

## 1:55-2:25 · 行情、估值与同行

进入“行情与估值”，展示二十七个观测点和历史PE/PB试算的股本时点假设；缺少核验时不声称便宜昂贵。

进入“同行对比”，说明只有茅台、五粮液两家公司同期样本，不能据此推全行业排名。

## 2:25-3:00 · 继续研究与交付

进入研究清单勾选一项，说明只是用户核对状态。导出Markdown笔记：问题、模式、实际模型、AI引用、证据、来源和任务状态可以一起交付。JSON供结构化复核。

“即使页面筛选只看未知，导出仍保留本次维度内的完整证据，避免引用断链。产品价值是让结论可继续追问，而不是替用户做交易决策。”

## 常见追问

| 问题 | 建议回答 |
| --- | --- |
| 为什么需要AI？ | 问题表达多样，AI关联跨维度证据并提出验证问题；数字、口径和未知边界由程序控制。 |
| 数据可靠吗？ | 五个公开来源与关键页核验留痕；单源行情、股本时点和样本范围限制明确保留。 |
| 免费API不稳定怎么办？ | 单请求、缓存、冷却；服务过载时仅顺序尝试一次免费备用，失败仍可研究本地证据。 |
| 校验能证明结论正确吗？ | 不能。固定案例检查不构成完整语义验证，仍要沿原文复核。 |
| 下一步先做什么？ | 扩充真实问题的人工评审与数据更新能力，再考虑多标的。 |
